# عرض مشروع FORESEE - نظام التنبؤ الذكي بالأحداث

## نظرة عامة
تم إنشاء هذا العرض التقديمي بناءً على وثيقة المشروع "توثيق المشروع v1.6.pdf" المتوفرة في المستودع.

## محتويات العرض التقديمي

العرض التقديمي يحتوي على 13 شريحة باللغة العربية:

1. **الشريحة الأولى**: العنوان والأسماء والمشرف
   - عبد الوهاب صالح المصراتي
   - عبد المهيمن عبد الوهاب حلمي  
   - المشرف: د. عبد السلام نوري بريون

2. **الشريحة الثانية**: المحتويات
3. **الشريحة الثالثة**: المقدمة
4. **الشريحة الرابعة**: محتوى المشروع
5. **الشريحة الخامسة**: الأهداف
6. **الشريحة السادسة**: أنواع المستخدمين
7. **الشريحة السابعة**: الوظائف
8. **الشريحة الثامنة**: التقنيات والأدوات المستخدمة
9. **الشريحة التاسعة**: مراحل المشروع
10. **الشريحة العاشرة**: الجانب العملي (مع مكان للفيديو)
11. **الشريحة الحادية عشرة**: الجدول الزمني
12. **الشريحة الثانية عشرة**: آفاق التطوير
13. **الشريحة الأخيرة**: الخاتمة

## معلومات التقنية
- **اسم الملف**: `عرض_مشروع_FORESEE.pptx`
- **التقنيات المستخدمة**: React Native, Nest.js, GraphQL, Machine Learning
- **المجال**: الذكاء الاصطناعي والتحليل التنبؤي
- **التطبيق**: التنبؤ بحوادث سرقة السيارات وتشخيص السكري

## كيفية الاستخدام
1. قم بتحميل الملف `عرض_مشروع_FORESEE.pptx`
2. افتح الملف باستخدام Microsoft PowerPoint أو LibreOffice Impress
3. يمكن إضافة الفيديو التوضيحي في الشريحة العاشرة
4. قم بتخصيص المحتوى حسب الحاجة
